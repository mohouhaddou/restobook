# Configuration

Ce dossier centralise les manifestes déclaratifs de l’infrastructure.

- `editors.json` inventorie les rédactions disponibles et leurs ressources.
- `publisher.json` décrit les futurs paramètres du publisher, désactivé par
  défaut.
- `paths.json` fournit les chemins relatifs canoniques sous `ai/`.

Ces fichiers ne contiennent aucun secret, endpoint, identifiant de base de
données ou paramètre d’API.
