# Workflows

Les fichiers de ce dossier sont des spécifications éditoriales lisibles par
les équipes. Ils décrivent les entrées, étapes, contrôles et sorties attendus,
sans orchestrateur ni code exécutable.

Chaque workflow d’éditeur aboutit conceptuellement à un `EditorResult`. Le
workflow `publish.md` décrit ensuite le cycle théorique d’un `PublisherJob`.
